# Security Policy

## Supported Versions

Only the latest deployed version of Cognitive Interval Timer is supported.

## Reporting a Vulnerability

If you find a security issue, open a GitHub issue with enough detail to reproduce it.
Do not include sensitive personal data in the report.

This is a client-side static app with no backend service. Security reports should focus on issues in the shipped app code, service worker, PWA behavior, or dependency/tooling configuration.
